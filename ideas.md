# Brainstorm de Design - Portfólio Gabriel Rangel

## Contexto
Site de portfólio para editor de vídeo Gabriel Rangel com 6 anos de experiência. Necessário transmitir profissionalismo, criatividade e expertise em edição de vídeo. Referência visual: tema escuro com detalhes vibrantes (roxo, azul, laranja).

---

## Abordagem 1: Cyberpunk Editorial (Probabilidade: 0.08)

**Design Movement:** Cyberpunk/Tech-Forward com influência de design editorial dos anos 90

**Core Principles:**
- Tipografia ousada e assimétrica com contraste extremo
- Camadas de profundidade com sobreposição de elementos
- Uso de cores neon contra fundo escuro quase preto
- Estrutura quebrada e dinâmica, evitando simetria

**Color Philosophy:**
- Fundo: #0a0e27 (preto profundo com toque azulado)
- Primário: #ff006e (magenta/rosa neon) + #00f5ff (cyan)
- Secundário: #ff6b35 (laranja quente) para CTAs
- Acentos: Gradientes roxo→magenta para profundidade
- Intenção: Transmitir energia, inovação e movimento

**Layout Paradigm:**
- Grid quebrado com elementos sobrepostos
- Hero com imagem de perfil em canto diagonal com borda neon
- Seções com clip-path para criar ângulos dinâmicos
- Vídeos em layout em cascata, não grid uniforme
- Texto posicionado em ângulos para criar movimento visual

**Signature Elements:**
1. Linhas neon (glow effect) separando seções
2. Badges com borda neon e fundo transparente
3. Glitch effects sutis em hover de elementos
4. Ícones de ferramentas com estilo tech/código

**Interaction Philosophy:**
- Hover com glow intenso e mudança de cor
- Cliques com efeito de ripple/onda
- Transições rápidas (200-300ms) para sensação de reatividade
- Modal com entrada de cima com blur de fundo

**Animation:**
- Entrada de elementos com fade + slide diagonal
- Hover com aumento de glow e mudança de saturação
- Transições de cor suave (300ms) em botões
- Scroll trigger: elementos aparecem com efeito parallax sutil

**Typography System:**
- Display: Space Mono (monospace bold) para títulos - transmite tech
- Body: Inter Light/Regular para legibilidade
- Hierarquia: Títulos em UPPERCASE com tracking amplo, corpo em sentence case

---

## Abordagem 2: Minimalismo Moderno com Textura (Probabilidade: 0.07)

**Design Movement:** Minimalismo contemporâneo com influência de design nórdico + textura

**Core Principles:**
- Máxima legibilidade com mínimo de elementos
- Uso estratégico de espaço negativo
- Tipografia como elemento principal de design
- Textura sutil (ruído, padrão) para evitar flatness

**Color Philosophy:**
- Fundo: #121212 (preto muito escuro, neutro)
- Primário: #e63946 (vermelho vibrante, único acento)
- Secundário: Tons de cinza (#e0e0e0, #a0a0a0)
- Acentos: Branco puro para contraste máximo
- Intenção: Sofisticação, foco no conteúdo, profissionalismo

**Layout Paradigm:**
- Seções com espaçamento generoso (padding 80px+)
- Alinhamento à esquerda com hierarquia clara
- Hero com imagem de perfil à direita, texto à esquerda
- Grid simples 2-3 colunas para vídeos
- Seções separadas por whitespace, não linhas

**Signature Elements:**
1. Linha vermelha vertical como divisor de seções
2. Números grandes em cinza claro para destacar experiência
3. Tipografia em diferentes tamanhos para criar ritmo
4. Cards com borda sutil, sem sombra

**Interaction Philosophy:**
- Hover com mudança de cor suave (vermelho → mais brilhante)
- Transições lentas (400ms) para elegância
- Sem efeitos disruptivos, apenas mudanças de cor/opacidade
- Cliques com feedback visual mínimo

**Animation:**
- Fade in ao scroll (entrada suave)
- Hover com mudança de cor e aumento de weight da fonte
- Transições de 400-500ms para sensação de refinamento
- Scroll: elementos se revelam gradualmente

**Typography System:**
- Display: Poppins Bold para títulos - moderno e limpo
- Body: Inter Regular para corpo - máxima legibilidade
- Hierarquia: Títulos grandes (48-64px), corpo 16px, labels 12px

## Abordagem 3: Rascunho Profissional (Sketch-Based) (Probabilidade: 0.06)

**Design Movement:** Design editorial com influência de rascunho/sketch, estilo "work-in-progress" refinado

**Core Principles:**
- Aparência de rascunho mas com execução profissional
- Tipografia com variações (itálico, maiúscula mista)
- Elementos desalinhados propositalmente para criar movimento
- Uso de anotações/notas visuais como elemento de design

**Color Philosophy:**
- Fundo: #0f0f0f (preto com toque de cinza)
- Primário: #ff6b35 (laranja conforme referência)
- Secundário: #a855f7 (roxo) para complemento
- Acentos: Branco e tons de cinza para anotações
- Intenção: Criatividade, autenticidade, processo visível

**Layout Paradigm:**
- Elementos levemente desalinhados (rotação 1-3 graus)
- Caixas com borda desenhada (stroke variável)
- Anotações visuais tipo "post-it" em cantos
- Vídeos em layout orgânico, não grid perfeito
- Linhas conectando seções como em um moodboard

**Signature Elements:**
1. Caixas com borda "desenhada" (border-radius variável)
2. Anotações em fonte manuscrita para destaque
3. Linhas conectoras entre elementos
4. Sombras suaves com blur para profundidade
5. Ícones estilo "doodle"

**Interaction Philosophy:**
- Hover com rotação sutil (1-2 graus) e mudança de cor
- Cliques com efeito de "pressão" (scale down)
- Transições naturais (300-400ms)
- Modal com entrada de forma orgânica

**Animation:**
- Entrada com fade + rotação sutil
- Hover com rotação e mudança de cor
- Scroll: elementos se revelam com efeito parallax
- Transições suaves e naturais (não rígidas)

**Typography System:**
- Display: Poppins Bold com variações (itálico, maiúscula mista)
- Body: Inter Regular para legibilidade
- Anotações: Caveat (manuscrita) para destaques
- Hierarquia: Títulos grandes com variação de estilo, corpo em tom claro

---

## Decisão Final

**Abordagem Escolhida: Rascunho Profissional (Sketch-Based)**

Esta abordagem melhor captura o espírito da imagem de referência fornecida, que mostra um estilo editorial criativo com elementos desalinhados e uma sensação de "projeto em andamento" mas profissional. Combina:

- A criatividade e autenticidade necessária para um portfólio de editor de vídeo
- O profissionalismo exigido por um freelancer com 6 anos de experiência
- A estética visual que você descreveu: escuro, com detalhes vibrantes (laranja #ff6b35, roxo)
- A grafia criativa "PoRtfólio VIDEO editorR" se encaixa perfeitamente neste estilo
- O botão "Cancelar OK" com estilo de rascunho/retro é natural nesta abordagem

**Elementos-chave a implementar:**
- Tipografia Poppins Bold para títulos com variações de estilo
- Fundo #0f0f0f com acentos em #ff6b35 (laranja) e #a855f7 (roxo)
- Elementos com rotação sutil e bordas "desenhadas"
- Layout orgânico para vídeos, não grid perfeito
- Anotações visuais e linhas conectoras
- Animações suaves e naturais com efeito parallax
